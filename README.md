\# Titanic Data Analysis 泰坦尼克号生存率数据分析



\##  项目简介

本项目基于泰坦尼克号乘客数据集，使用 Python (Pandas, Matplotlib, Seaborn) 进行数据探索、特征提取与可视化分析，旨在挖掘影响乘客生存率的关键因素。



\## 核心发现 

1\. \*\*性别与生存率\*\*：女性生存率（约74%）远高于男性（约18%），印证了“女士优先”的救援原则。

2\. \*\*阶级与生存率\*\*：头等舱生存率最高，三等舱最低。富有和地位高的乘客获救概率更大。

3\. \*\*特征工程 (Title)\*\*：通过正则表达式从姓名中提取头衔（Mr, Mrs, Miss, Master），发现小男孩（Master）生存率极高，而成年男性（Mr）生存率极低。

4\. \*\*混杂变量探讨\*\*：验证了“三等舱男性基数大拉低整体男性生存率”的假设。交叉分析显示，即使在同等舱位下，女性生存率依然远高于男性，说明性别规则跨越了阶级；但头等舱男性的生存率优于三等舱女性，体现了阶级壁垒。
